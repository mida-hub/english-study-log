# English Study Log

中学1年生レベルから始めて、段階的に英語力（英単語・リーディング・ライティング）を伸ばしていくための学習記録リポジトリです。

## 学習方針
- **対象分野**: 英単語・リーディング・ライティング（英会話は別サービスで実施）
- **進め方**: Markdown ベースで 1 セッション 15〜20 分を目安に実施
- **記録**: 学習ログ・復習単語・カリキュラム進捗をすべて Git で管理

## 1回の学習サイクル
1. **出題（AI）**: `sessions/YYYY-MM-DD.md` を作成し、英単語（5問）・リーディング（1題）・ライティング（1〜2題）を出題
2. **回答（ユーザー）**: 同ファイル内の回答欄に記入して保存
3. **採点・添削・アドバイス（AI）**: 採点結果・自然な表現への添削・解説を同ファイルに追記し、苦手単語を `vocabulary/review.md` に追加、`curriculum.md` の進捗を更新

## ディレクトリ構成
```text
english-study-log/
├── README.md              # 学習ルール・全体概要
├── curriculum.md          # カリキュラムと進捗チェックリスト
├── sessions/              # 日々の学習ログ（YYYY-MM-DD.md）
├── vocabulary/            # 復習が必要な単語リスト（review.md）
└── .agents/skills/        # 学習サポート用スキル（english-tutor）
```
